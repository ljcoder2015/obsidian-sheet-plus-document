# Introduction

## What is a Dashboard?

A dashboard is a visual representation of data that allows you to analyze it.

![dashboard](dashboard.gif)

## Supported Components

- Time Component
  - Display current time
  - Countdown
- Calendar Component
- Chart Component
  - Bar
  - Line
  - Pie
  - Candlestick
  - TreeMap
  - Funnel
  - Word Cloud
  - Stage
