# Quick Start

## What is REST API
The REST API allows you to access and manipulate spreadsheet data using the HTTP protocol. For example, you can retrieve data from a spreadsheet or update data in a spreadsheet via the REST API.

It also supports AI clients like Claude to call the REST API by adding the `obsidian-sheet-plus-mcp-server`.
