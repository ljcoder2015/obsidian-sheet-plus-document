# Import & Export <Badge text="License Required" type="warning" />

::: warning License Required
Import and Export features are **available only after license activation**.
:::

Click the import/export menu in the toolbar to import/export spreadsheet files.

![alt text](image-6.png)

---

- Supported Formats

  * `.xlsx`
  * `.csv`

---

- Supported Features

| Feature | import | export |
| --- | --- | --- |
| Text | ✔ | ✔ |
| Style | ✔ | ✔ |
| Floating Image | ✔ | ✔ |
| Cell Image | ✖ | ✖ |
| Formula | ✔ | ✔ |
| Note | ✖ | ✔ |
| Hyperlink | ✖ | ✔ |
